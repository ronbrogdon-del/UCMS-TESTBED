# Intervention Windows: Existence vs. Detectability

Standalone note. Captures the key distinction so it can be carried into a fresh
chat or read on its own.

## The defensible claim
Failing to find a working precursor operator does NOT mean upstream intervention
windows don't exist structurally. "We couldn't build a detector for X" is not
evidence that "X doesn't exist." Absence of a working measurement is not absence
of the phenomenon.

## Three separate claims (keep them separate)
1. **Upstream windows CAN exist structurally** — TRUE, and untouched by this
   session's failed precursor search. This is the safe, airtight claim.
2. **Upstream windows DO exist in these systems** — open question, not
   established.
3. **My Δ₂ windows are real, validated intervention windows** — still pending a
   null-tested validation (matched stable/null segments + held-out real data,
   falsifiability stated before the comparison).

The failed directional-precursor search leaves (1) fully intact and says nothing
about (2) or (3) either way. The statement tips into overclaim only if it slides
into "therefore they do exist" or "therefore my windows are validated." It
should not.

## The structural argument for (1) — independent of any operator
If a system moves through an orthogonal state-space toward a rupture boundary
along a continuous trajectory, then by construction it occupies pre-rupture
geometry before it ruptures — there is some interval where it is measurably
closer to the boundary but has not yet crossed. That interval is a structural
intervention window almost by definition.

The hard part was never whether such an interval EXISTS. It was whether any
operator can reliably DETECT it against noise, early enough, without
false-alarming. The detection problem failed this session. The existence claim
never depended on it.

## Bottom line
- Existence of the window: implied by the geometry; not in question.
- Detectability of the window: the honest open frontier; four operationalizations
  failed; question still open.
- Stated at true size: the window can exist structurally; whether it is
  detectable — and whether the existing Δ₂ windows are validated — remains to be
  shown.
