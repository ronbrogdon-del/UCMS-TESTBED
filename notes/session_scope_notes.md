# Session Notes — What Was and Wasn't Established (Scope Discipline)

A plain-language record of what this session's testing actually showed, written
to prevent the record from drifting in either direction — inflated up
("breakthrough / mature discipline") or inflated down ("retract everything").
Both are the same error: the written claim moving faster than the evidence.

---

## The three things, kept separate

1. **Directional precursor operator (the NEW thing we tried to build):**
   A signal that identifies *which axis* is destabilizing, ideally *earlier*
   than Δ₂. Four operationalizations tested: CCV(t), naive coupling, naive
   eigenstructure, AR(1) slowing.
   **Result: all four failed their specific tests.** Question still open — "not
   these four, on this data, at this scale," NOT "no such signal exists."

2. **Δ₂ curvature-inversion precursor windows (the EXISTING capability):**
   The 14–120 day leads, ERCOT ~8.9h mean, corpus precursor windows.
   **Result: NOT TESTED this session.** Status unchanged — neither confirmed
   nor refuted by today's work. Stands on whatever evidence it had before
   (much of it synthetic/calibrated-illustrative — its own separate open
   question, but a pre-existing one, not created today).

3. **Deterministic core (Δ₁ variance collapse, τ½ stability, orthogonal
   workspace):** Untouched this session. Stands where it stood.

## The key correction
Failing to build the new directional operator tells us NOTHING about the
existing Δ₂ windows or the deterministic core. Today was an attempt to add a
wing; the wing didn't hold; the existing structure is exactly as sound (or as
in-need-of-its-own-inspection) as it was yesterday.

## The two-directional overstatement risk (the thing to watch)

This session produced two artifacts that both reached past the evidence, in
opposite directions:

- **Upward inflation:** "the discipline is now real / mature / immune to drift,"
  CCCV(t) as "civilizational-grade / highest-order operator," "first / only."
  → Asserted properties instead of demonstrating them.

- **Downward inflation:** a Zenodo-ready self-correction paper retracting the
  Δ₂ precursor claims.
  → Confessed to overstating something this session never tested; also
  mischaracterized the directional-operator results (called eigenstructure
  "promising / silent on nulls" when the 50-seed MC showed 46–56% false
  positives). A retraction of untested claims is itself an inaccuracy.

Both have the same shape: velocity outrunning evidence. The steady-state truth
sits calmly between them and does not move much (see the three things above).

**Rule that falls out of this:**
- Strike every superlative before anything goes public (first, only, highest,
  unprecedented, civilizational, "the discipline is now real"). Each is a claim
  that would have to be defended and can't; one indefensible claim lets a
  hostile reader dismiss the defensible ones.
- A public self-correction must be as evidence-bound as a public claim. Don't
  retract what wasn't tested.
- The written artifact says only what was demonstrated — nothing larger,
  nothing smaller.

## The genuinely high-value next experiment
Not a new operator. A proper **null-tested validation of the existing Δ₂
precursor windows** — matched stable/null segments + held-out real data, with
falsifiability stated before the comparison (earlier or more specific than
baseline AND silent on matched nulls). That would actually tell you whether the
current intervention windows are real. Only after that test would any
self-correction (or confirmation) about Δ₂ be evidence-bound.
